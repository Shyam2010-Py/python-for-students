Module 01

Introduction to Python

What is Python and why should you learn it?

📘 Explanation

Python is a high-level, easy-to-read programming language created by Guido van Rossum in 1991. It is one of the most popular languages in the world because its syntax looks almost like English.

Python is used for:

  • 🌐 Web Development
  • 🤖 Artificial Intelligence & Machine Learning
  • 📊 Data Science
  • 🛠️ Automation & Scripting
  • 🎮 Game Development

💡 Why Python for Students?

✅ Beginner friendly — easy syntax
✅ Free & Open Source
✅ Huge community support
✅ In-demand career skill

⚙️ How to Install Python

  1. Go to python.org
  2. Download the latest version (3.12+)
  3. Run the installer and tick "Add Python to PATH"
  4. Open Terminal / CMD and type python --version

No installation? Use replit.com or Programiz online compiler.

Module 02

Hello, World!

Your first Python program.

📘 Explanation

Every programmer's first program prints the text Hello, World! on the screen. In Python, we use the print() function to display output.

🧾 Syntax

print("your text here")

💻 Example Code 

print("Hello, World!")
print("My name is Aarav.")
print("I am learning Python!")
Expected Output:
Hello, World!
My name is Aarav.
I am learning Python!

Module 03

Variables

Storing information in a program.

📘 Explanation

A variable is a name that stores a value. Think of it as a labelled box where you keep data. In Python, you don't need to declare the type — just assign a value.

🧾 Syntax

name = value

📚 Data Types

  • int — whole numbers, e.g. 10
  • float — decimal numbers, e.g. 3.14
  • str — text, e.g. "Hello"
  • bool — True / False

💻 Example Code 

name = "Aarav"
age = 17
height = 5.8
is_student = True

print("Name:", name)
print("Age:", age)
print("Height:", height)
print("Student:", is_student)
Expected Output:
Name: Aarav
Age: 17
Height: 5.8
Student: True

✏️ Practice Question

Module 04

Input and Output

Talking with the user.

📘 Explanation

Output means showing something to the user using print().
Input means taking something from the user using input(). The input() function always returns a string.

🧾 Syntax

value = input("Enter something: ")
print(value)

💻 Example Code 

name = input("Enter your name: ")
age = int(input("Enter your age: "))

print("Hello", name)
print("You will turn", age + 1, "next year!")
Expected Output (if user types Aarav and 17):
Hello Aarav
You will turn 18 next year!

🔁 Type Casting

x = int("10")     # string → int
y = float("3.5")  # string → float
z = str(100)      # int → string

✏️ Practice Question

Ask the user for two numbers, add them, and print the result.

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
sum = a + b
print("The sum is:", sum)
Module 05

If-Else Statements

Making decisions in your code.

📘 Explanation

Conditional statements let your program make choices. If a condition is True, one block runs; otherwise, another runs.

🧾 Syntax

if condition:
    # code
elif another_condition:
    # code
else:
    # code

💻 Example Code 

marks = int(input("Enter your marks: "))

if marks >= 90:
    print("Grade: A+")
elif marks >= 75:
    print("Grade: A")
elif marks >= 50:
    print("Grade: B")
else:
    print("Grade: C — Work harder!")
Expected Output (if input is 82):
Grade: A

🔍 Comparison Operators

  • == equal to
  • != not equal to
  • > < >= <=

✏️ Practice Question

    print("Eligible to vote")

    print("Not eligible")
Module 06

Loops

Repeating tasks automatically.

📘 Explanation

Loops let you run a block of code multiple times. Python has two main loops: for and while.

🧾 Syntax

# for loop
for i in range(start, stop):
    # code

# while loop
while condition:
    # code

💻 Example 1 — For Loop 

for i in range(1, 6):
    print("Number:", i)
Expected Output:
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5

💻 Example 2 — While Loop 

count = 5
while count > 0:
    print(count)
    count -= 1
print("Done!")
Expected Output:
5
4
3
2
1
Done!

✏️ Practice Question

Module 07

Functions

Reusable blocks of code.

📘 Explanation

A function is a named block of code that performs a specific task. You define it once and call it whenever you need it.

🧾 Syntax

def function_name(parameters):
    # code
    return value

💻 Example Code 

def greet(name):
    print("Hello,", name, "!")

def add(a, b):
    return a + b

greet("Aarav")
result = add(10, 20)
print("Sum is:", result)
Expected Output:
Hello, Aarav !
Sum is: 30

✏️ Practice Question

    return n * n

print("Square of 5 is:", square(5))
Module 08

Lists

Storing many values in one variable.

📘 Explanation

A list is a collection of items stored in a single variable. Lists are ordered, changeable, and allow duplicates. They are written with square brackets [ ].

🧾 Syntax

my_list = [item1, item2, item3]

💻 Example Code 

fruits = ["apple", "banana", "cherry", "mango"]

print(fruits)
print("First fruit:", fruits[0])
print("Last fruit:", fruits[-1])

fruits.append("orange")
print("After adding:", fruits)

print("Length:", len(fruits))
Expected Output:
['apple', 'banana', 'cherry', 'mango']
First fruit: apple
Last fruit: mango
After adding: ['apple', 'banana', 'cherry', 'mango', 'orange']
Length: 5

🛠️ Common List Methods

  • append(x) — add item at end
  • remove(x) — remove first matching item
  • pop(i) — remove at index
  • sort() — sort the list
  • len(list) — count items
